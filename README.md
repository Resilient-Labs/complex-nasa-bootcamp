### JavaScript API Integration Project

## About the Project

This assignment focuses on building an application that displays NASA facility locations along with the current weather at each location.

The goal is to practice working with multiple APIs and combining information from different sources into one application.

Instead of displaying information from just one API, this project is about understanding how to retrieve location data, use it to request weather information, and present everything in a way that's easy to understand.

## Project Goals

- Retrieve NASA facility information from an API.
- Display the name and location of each facility.
- Retrieve current weather conditions for each location.
- Combine facility and weather information.
- Display the results on a webpage.

## Planned Tech Stack

- HTML5
- CSS3
- JavaScript
- Fetch API
- NASA facility data
- Weather API

## How It Would Work

1. The application requests NASA facility information.
2. JavaScript reads the returned facility names and locations.
3. The application uses the location information to request weather data.
4. The results are combined to display each facility alongside its weather conditions.

## Concepts to Practice

- Working with multiple APIs.
- Making asynchronous requests using `fetch()`.
- Understanding JSON responses.
- Working with arrays and objects.
- Combining data from different sources.
- Using DOM manipulation to display information.
- Handling errors and missing data.


## Next Steps

1. Identify a suitable source for NASA facility data.
2. Choose a weather API.
3. Build the application interface.
4. Connect the APIs and combine their responses.
5. Add error handling and improve the presentation.
6. Test the application and upload the completed code.
